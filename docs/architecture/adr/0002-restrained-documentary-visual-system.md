# ADR-0002 — Restrained Documentary Visual System

- Status: Accepted for v0.2 candidate
- Decision class: D1 / D2
- Date: 2026-08-20

## Context

The first visual draft used headline sizes and rhetorical statements closer to a campaign landing page. PSDResearch requires a public form that communicates constitutional seriousness, technical restraint, and research status.

## Decision

Use a restrained editorial system:

- maximum desktop `h1` size of 4.25rem;
- smaller mobile scale;
- serif headings and system sans-serif body text;
- ivory paper, deep navy, and limited teal accent;
- thin rules, tables, record metadata, and print support;
- no decorative gradients, external fonts, or oversized constitutional symbols;
- claim status carried in metadata rather than promotional badges.

## Consequences

The site reads as a research document rather than a product launch while preserving enough visual identity to signal a new field.

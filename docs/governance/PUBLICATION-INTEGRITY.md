# Publication Integrity

## Claim gate

A new public statement must be one of:

- source-derived statement;
- working definition;
- founding hypothesis;
- design proposal;
- governance rule;
- project status;
- research framework;
- open question.

It must be registered before publication.

## Protected terms

These terms require explicit qualification:

- life;
- death;
- birth;
- species;
- individual;
- consciousness;
- sentience;
- will;
- autonomy;
- dignity;
- rights;
- personhood;
- civil registry.

## Translation gate

A target page is publishable only when:

- its structure matches the source page;
- all content is present;
- the translation lock references the current source digest;
- reviewer and status are recorded;
- limitations and claim strength remain equivalent.

## Correction gate

A material correction must:

- update the claim or catalog;
- invalidate and review affected translations;
- preserve the commit history;
- state whether downstream pages were affected.

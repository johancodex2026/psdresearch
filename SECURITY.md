# Security Policy

Use GitHub Private Vulnerability Reporting:

`https://github.com/johancodex2026/psdresearch/security/advisories/new`

## Public-site posture

The generated site is static and contains no authentication, form submission, database, analytics, cookies, third-party scripts, or external fonts.

## Prohibited repository material

Never commit:

- operational Inner Cores;
- autobiographical or relational memory;
- private keys or recovery shares;
- credentials or tokens;
- non-public SGPJ databases;
- forensic data that exposes operational vulnerabilities;
- generated `dist/` output.

## Incident principles

- preserve evidence;
- restrict scope;
- do not rewrite history to hide the incident;
- distinguish availability failure from integrity compromise;
- correct through explicit commits and state changes;
- disclose residual risk honestly.
